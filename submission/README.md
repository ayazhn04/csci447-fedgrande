## Notebook

What the notebook does:
- Loads the dataset, rebuilds the leakage groups and the grouped splits, and runs the label-free federated
  preprocessing. These steps are executed in full.
- Shows the GRANDE model, FedAvg with local Adam, and the consensus-gated freezing rule.
- Recomputes every reported metric, table and figure from the saved predictions and training logs in `artifacts/`.
  This covers the hold-out split, 5-fold cross-validation, training curves, confusion matrix, ROC curves,
  heterogeneity, calibration, communication, and the state-of-the-art comparison.

The notebook does not retrain the experiment matrices, which took about 21 CPU-hours. It asserts its results against
the frozen experiment outputs, and a full Run All takes about 15 seconds.

To run it, open the notebook in this folder and choose Run All. It needs Python 3.12 with numpy, pandas, scipy,
scikit-learn, matplotlib and torch (the versions are in `../environment.yml`).

`artifacts/` was generated by `../scripts/build_submission_artifacts.py`. `artifacts/provenance.json` records the
source files, the experiment commit (tag `experiments-final`) and a checksum for every file.
