# Results ledger

This page holds the exact numbers likely to be needed in the report and slides.

**The tables between the GENERATED markers are written by `scripts/build_curated_results.py`** (`make summaries`) from
the saved phase summaries. Do not edit them by hand. `make check` fails if they drift.
- Machine-readable copies with provenance: [`results/curated/`](../results/curated/README.md).
- Single key numbers: [`results/curated/final_key_numbers.json`](../results/curated/final_key_numbers.json).

**How to read the tables:**
- AUC = ROC-AUC on the held-out test folds.
- "Pooled OOF" = the 5 folds' test predictions pooled, per seed, then mean ± SD over seeds 42/447/2026.
- "Fold" = mean of the 5 per-fold AUCs.
- ΔAUC = method − reference, paired by (partition, seed).
- GB = conceptual tensor bytes over 21 clients, downlink + uplink, including initialization.
- No p-values: fold × seed runs are not independent.

## Which table supports which claim

| Claim in the report | Table | Notes |
|---|---|---|
| FedAvg GRANDE retains most centralized performance; collaboration beats local training | Main performance | Quote pooled OOF; per-fold agrees. |
| Natural waves ≈ IID control; label skew is much harder | Heterogeneity | Use the **fold** AUC for Dirichlet: pooled OOF is distorted. |
| Consensus is high by round 20 and lower under label skew | Heterogeneity | Association between regimes only (see CLAIMS_AND_LIMITATIONS). |
| Calibration, not personalization, explains the label-skew benefit | Personalization | Use within-client AUC (A1) and log loss; **not** the aggregate fold AUC (client-identity effect). |
| INT8 is free; fewer trees trade AUC for bytes | Static compression | Ratios are conceptual bytes. |
| Structure is 98% of the payload; freezing it after round 20 preserves AUC | Fixed structural freezing | Band: \|ΔAUC\| ≤ 0.005 = essentially preserved. |
| Consensus gating rediscovers round about 20 but does not improve it | Adaptive freezing | G2's pooled ΔAUC is driven by 2 early-stopped runs; per-fold AUC = F2. |
