## Why the project moved from phase to phase

1. **2A** showed that the historical row-wise evaluation was structurally leaky. Every later phase therefore uses
   grouped folds.
2. **2B** found FedAvg works and natural ≈ IID. The heterogeneity question then needed a stronger contrast, which was
   the Dirichlet stress test (A1).
3. **2B-A1/A3** found that label skew mostly breaks *calibration*. **2C** asked whether personalization of tree outputs
   does better than recalibration. It does not.
4. **2B** showed that GRANDE costs 136 MB per round. **2D** tried static compression.
5. **2B** showed structural consensus near 0.98 by round 20, and 2E's Gate 0 showed structure is 98% of the payload.
   **2E** froze structure after round 20.
6. **2F** asked whether the freeze round could be chosen automatically from consensus. It can, but not better.
